# Anime Automation Madness

*From a few scripts to a big system.*

## About this project

This project is an educational journey through the evolution of a personal automation system, from a handful of scripts to a much larger architecture.

It explores how existing tools, scripting, system administration, and software development can come together to solve practical problems.

**This is not a turnkey solution or a complete software distribution.** The goal is to share the ideas, decisions, and experiments that shaped the system, rather than provide a ready-to-use solution.

Some original scripts are available separately as archived repositories for historical and educational purposes.
